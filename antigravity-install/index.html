WHY ANTIGRAVITY

왜 웹 AI가 아니라 Antigravity를 사용하나요?

이번 교육의 목표는 AI와 대화하는 방법만 배우는 것이 아닙니다. 내 PC의 작업 폴더에서 실제 업무 파일을 만들고 수정하며, 앞 시간의 결과를 다음 실습에 이어 쓰는 업무 흐름을 익히는 것이 목표입니다.

웹 AI 예시 (chatgpt.com · claude.ai · gemini.google.com)

1

대화가 아니라 파일이 남습니다

웹 AI의 답변은 주로 대화창에 남지만, Antigravity는 지정한 작업 폴더에 문서와 결과물을 실제 파일로 만들고 수정할 수 있습니다.

2

여러 단계의 업무가 이어집니다

dna.md 작성부터 업무 온톨로지맵, 대시보드, 규격 비교표, AI 적용 과제정의서까지 앞 단계의 결과물을 다음 단계에서 계속 활용합니다.

3

교육 후에도 이어 쓸 수 있습니다

실습 결과가 본인 노트북의 파일로 남기 때문에 교육 다음 날에도 같은 폴더를 열어 업무에 적용하거나 내용을 보완할 수 있습니다.

한 문장으로 정리하면 — 웹 AI가 답을 받는 도구라면, Antigravity는 업무 결과물을 파일로 남기고 이어서 완성하는 실습 도구입니다.

보안·데이터 주의 — Antigravity가 내 PC의 파일을 다루더라도 AI 처리를 위해 파일 내용이 외부 서비스로 전송될 수 있습니다. 고객 원본, 시험성적서 원본, 표준 원문, 개인정보와 대외비 자료는 사용하지 않고 공개 자료나 익명화한 사본만 사용합니다.

DEVICE CHECK

먼저 내 노트북이 되는지 확인해 주세요

Windows

Windows 10 또는 11

  • 64비트 운영체제여야 합니다.
  • 여유 공간 5GB 이상이 필요합니다.
  • 프로그램 설치를 위한 관리자 권한을 확인해 주세요.

운영체제 확인 방법
Windows 키를 누르고 winver를 입력한 뒤 Enter → Windows 10 또는 11이면 정상입니다.
64비트 확인 · 설정 → 시스템 → 정보 → 시스템 종류

macOS

macOS 12 Monterey 이상

  • Apple Silicon(M1 이상) 모델이어야 합니다.
  • 여유 공간 5GB 이상이 필요합니다.

운영체제·칩 확인 방법
화면 왼쪽 위 사과 메뉴 → 이 Mac에 관하여 → macOS 버전과 칩 항목을 확인합니다.

칩 항목이 Intel이면 신청 시 꼭 알려 주세요. 설치본이 Apple Silicon 전용이라 Intel Mac에서는 실행되지 않습니다.

INSTALL 01

Antigravity 2.0을 설치해 주세요

Antigravity 공식 사이트 열기 ↗
Windows
  1. 공식 사이트에서 Windows용 설치 파일을 내려받습니다.
  2. 설치 파일을 실행하고 화면 안내에 따라 설치합니다.

  1. 공식 사이트에서 macOS용 설치 파일을 내려받습니다.
  2. Apple Silicon용인지 확인하고 화면 안내에 따라 설치합니다.

INSTALL 02

Google Cloud SDK를 설치해 주세요

본인 운영체제 카드의 설치 버튼을 먼저 누른 뒤, 아래 세 단계만 따라가면 됩니다.

Windows

명령어 입력 없이 바로 설치합니다

Windows 설치 파일 바로 받기 ↓

버튼을 누르면 GoogleCloudSDKInstaller.exe 다운로드가 시작됩니다.

  1. 다운로드된 GoogleCloudSDKInstaller.exe 파일을 실행합니다.
  2. 설치 화면의 옵션은 변경하지 않고 기본값 그대로 진행합니다.
  3. 설치가 끝나면 컴퓨터를 한 번 재시작합니다.
macOS · ARM64

Apple Silicon용 설치 안내를 확인합니다

macOS 설치 안내 보기 ↗

공식 페이지에서 macOS 탭을 선택하고, ARM64 · Apple silicon 항목만 확인해 주세요.

  1. ARM64 · Apple silicon 설치 파일을 내려받습니다.
  2. 공식 페이지에 표시된 순서대로 설치합니다.
  3. 설치가 끝나면 터미널을 완전히 닫고 다시 실행합니다.
